# 🏦 Bank Management System

A desktop-based Bank Management System developed using **Java Swing**.

## ✨ Features

* Create new bank accounts
* Modify account information
* Close accounts
* Deposit money
* Withdraw money
* Multi-criteria account search
* Sort accounts by different fields
* Display account information in a GUI table
* Input validation and error handling

## 🛠️ Technologies

* Java
* Java Swing
* Object-Oriented Programming (OOP)
* Java Collections
* JTable & Swing Components

## 📌 Project Structure

The project contains:

* `Account` — Represents a bank account.
* `AccountManager` — Handles account management and business logic.
* `AccountTableModel` — Connects account data with the JTable.
* `BankManagementSystem` — Main Java Swing GUI.

## ▶️ How to Run

1. Make sure Java JDK is installed.
2. Clone the repository:

```bash
git clone https://github.com/esr470/Bank-Management-System.git
```

3. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
4. Run:

```text
BankManagementSystem.java
```

## 📚 Concepts Demonstrated

This project demonstrates Object-Oriented Programming, Java Swing GUI development, collections, sorting, searching, exception handling, and event-driven programming.
